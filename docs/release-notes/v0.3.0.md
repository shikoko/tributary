Beta versions you can choose to get, a tidier commit details panel, and links that show where they go.

## New

- **Beta versions:** turn on **Get beta versions** in **About Tributary** to try what's coming before it's released. You'll be offered the newest version, beta or released, and About marks a beta as **Beta**. Turning it off doesn't take you back: you keep the beta you have until a release is newer.
- **See where a link goes:** pointing at anything that opens a web page shows its address in the status bar at the bottom, the way browsers do.
- **Report on GitHub:** the error screen and **Help → Copy Diagnostics…** have a **Report on GitHub** button. It opens a new bug report in your browser with the details already filled in, so you can check them and send it yourself. Nothing is sent without you.
- **Open a mentioned pull request here:** when a commit mentions a pull request, its details have **Show**, which opens it in Tributary instead of the browser.
- **Told when an update is ready:** a few seconds after Tributary opens, it checks for a newer version, and says so once it's downloaded and ready to install.
- **Copy a branch's name:** click either branch on a pull request's page to copy its name. Right-click the pull request's branch to highlight its history.

## Better

- **A tidier commit details panel:** the message, checks, people, details and changed files each have their own small heading, with more room between them. The SHA has its own copy button under Details. Checks show how many failed, are running and passed, with a bar, and list the failed and running ones first.
- **Merged on the site, fetched here:** when one of the repository's pull requests is merged or closed on GitHub or GitLab, Tributary fetches, so the history shows it straight away.
- **Long check names:** a check's name that's too long to fit slides along to show the rest while you point at it.
- **A steadier checks timeline:** while checks run, bars stay where they started and running ones grow to the right, instead of everything creeping left every second.
- **Checks as tributaries:** each check's wave now runs on through the river in one line, so pointing at one after another doesn't flicker where they meet. A cancelled check no longer turns the river cyan.

## Installing

- **macOS:** the `.dmg`, one app for Apple Silicon and Intel. Open it and drag Tributary to Applications.
- **Windows:** the `-setup.exe` (64-bit): agree to the terms and click Install, or choose **Custom install** to install it for everyone on the PC or in another folder.

Tributary needs [git](https://git-scm.com), and [Git LFS](https://git-lfs.com) for repositories that use it. After this, it updates itself.

The installers aren't code-signed yet, so the first launch needs one extra step:

- **macOS, "Tributary Not Opened":** click **Done**, then open **System Settings → Privacy & Security**, scroll down to **Security** and click **Open Anyway** next to Tributary. Open it again and choose **Open Anyway**. On macOS 14 and earlier, you can instead Control-click the app in Applications and choose **Open**.
- **macOS, "is damaged" (or it still won't open):** move it to Applications and run `xattr -cr /Applications/Tributary.app` once in Terminal.
- **Windows:** if SmartScreen warns you, choose **More info → Run anyway**.

It's only needed once: the updates Tributary installs itself open straight away.

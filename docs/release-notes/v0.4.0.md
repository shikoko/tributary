A simpler branch list, and a window that opens where you left it.

## New

- **Each branch once:** the sidebar lists a branch and its copy on the remote as one row, with what there is to push and pull beside it. Your branch and the protected ones (like `main`) are at the top, and branches that are only on the remote are folded away under **Only on origin**. A branch that has never been pushed is marked with a laptop. Right-clicking a branch also offers its copy on the remote (**Delete … from origin**), and hiding it hides both. **Manage remotes** is the gear on the Branches heading.

## Fixes

- **The window opens where you left it:** on the same display, at the same place and size, maximised if it was, after an update too. If that display isn't connected, it opens on the main one. This starts with this version, so the restart into it still opens on the main display.
- **Branch names stay visible:** a branch's name is no longer squeezed out by the "on …" label beside it when it also has commits to push and pull.
- **Folded folders** in the sidebar now point their arrow to the side.
- **The checks timeline** says "Finished … ago" at the end of its clock.

## Installing

- **macOS:** the `.dmg`, one app for Apple Silicon and Intel. Open it and drag Tributary to Applications.
- **Windows:** the `-setup.exe` (64-bit): agree to the terms and click Install, or choose **Custom install** to install it for everyone on the PC or in another folder.

Tributary needs [git](https://git-scm.com), and [Git LFS](https://git-lfs.com) for repositories that use it. After this, it updates itself.

The installers aren't code-signed yet, so the first launch needs one extra step:

- **macOS, "Tributary Not Opened":** click **Done**, then open **System Settings → Privacy & Security**, scroll down to **Security** and click **Open Anyway** next to Tributary. Open it again and choose **Open Anyway**. On macOS 14 and earlier, you can instead Control-click the app in Applications and choose **Open**.
- **macOS, "is damaged" (or it still won't open):** move it to Applications and run `xattr -cr /Applications/Tributary.app` once in Terminal.
- **Windows:** if SmartScreen warns you, choose **More info → Run anyway**.

It's only needed once: the updates Tributary installs itself open straight away.
